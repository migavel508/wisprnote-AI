48/// Different types of audio units
49///
50/// Audio units are classified into different types, where those types perform different roles and
51/// functions.
52///
53/// There are some general categories of functionality that apply across different types of audio
54/// units:
55///
56/// 1. Real-time usage.
57///
58///    The audio unit will complete its operations in less time than is represented by the render
59///    buffer. All audio units with the exception of the OfflineEffect should meet this criteria.
60///
61/// 2. Real-time I/O.
62///
63///    Will request the same amount of audio input as it is being asked to produce for output.
64///    Effects, Panners, Mixers and MusicDevices are required to adhere to this restriction.
65///    FormatConverter's can with some constraints be used in this situation (for instance, sample
66///    rate conversion, float-int), but the host of the audio unit is responsible for insuring
67///    this.
68///
69/// 3. UI versus Programmatic usage.
70///
71///    UI usage covers the case of using an audio unit in a Digital Audio Workstation (DAW) with
72///    appropriate UI (for example a filter in Garage Band or Logic). Effects, Panners,
73///    MusicDevices are all expected to be usable within this context.
74///
75///    Programmatic usage is where an audio unit is used by a host app as part of a general signal
76///    processing chain.
77///
78///    For instance, a mixer audio unit can be used to take several different audio sources in a
79///    game and mix them together. Mixers, Output units are for programmatic usage. FormatConverter
80///    and Generator types are generally programmatic audio units, but if they can be used in a UI
81///    situation, they specify a custom view. The app can then use that to decide that, with
82///    appropriate constraints, the audio unit could be presented in a DAW type application. For
83///    instance, the AUConverter audio unit from apple can do sample rate conversion, etc, but has
84///    not general utility for a user in a DAW app. Apple's Varispeed or AUTimePitch audio units
85///    can be used to change the playback rate and pitch and so could be used to good affect by a
86///    user in a DAW type environment, as well as just providing this general functionality to any
87///    program.
