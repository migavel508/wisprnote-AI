1925/// Apple AUScheduledSoundPlayer Property IDs
1926///
1927/// The AUScheduledSoundPlayer audio unit lets a client schedule audio buffers for
1928/// future playback, with sample-accurate timing.
1929///
1930/// Elements and Formats
1931///
1932/// This unit has one output element and no input elements. The output's format
1933/// should be a canonical audio unit stream format (native Float32, deinterleaved).
1934///
1935/// Scheduling
1936///
1937/// To schedule slices of audio for future playback, set the
1938/// kAudioUnitProperty_ScheduleAudioSlice property, with a ScheduledAudioSlice
1939/// structure as the property value. The slice's mTimeStamp.mSampleTime field
1940/// determines when the slice will be played. This sample number is relative to
1941/// the unit's start time, which you must set using the
1942/// kAudioUnitProperty_ScheduleStartTimeStamp property before playback will
1943/// begin.
1944///
1945/// You must retain, unmodified, the ScheduledAudioSlice structure, including
1946/// its mBufferList and the buffers to which it points, until the slice has been
1947/// completely played, or until you stop playback by uninitializing or resetting
1948/// the unit. The format of the slice's buffer list must match the unit's output
1949/// stream format.
1950///
1951/// As of OS X 10.10 and iOS 8.0, you can use an invalid time stamp (no flags set
1952/// in mFlags) to indicate that the slice should be played immediately following the
1953/// previous slice (or immediately, if there are no slices playing).
1954///
1955/// (The fields other than mSampleTime and mFlags in the mTimestamp structure are
1956/// currently ignored.)
1957///
1958/// Completion
1959///
1960/// To receive a callback when the slice has been played, store a pointer to a
1961/// callback function in the mCompletionProc field. This function will be called
1962/// (from the audio unit's rendering thread) when the slice has been completely
1963/// played -- or when the slice is determined to be unplayable due to an error.
1964/// As an alternative, you may also poll the slice's
1965/// (mFlags & kScheduledAudioSliceFlag_Complete).
1966///
1967/// Upon completion, you can test (mFlags & kScheduledAudioSliceFlag_BeganToRenderLate)
1968/// to determine whether some portion of the slice was not played due to its having
1969/// been scheduled too late relative to the current playback time.
1970///                    
1971/// Start Time
1972///
1973/// The audio unit will not play any slices following initialization or reset, until
1974/// its start time has been set. The start time establishes the beginning of a
1975/// timeline: the timestamps of all slices in the schedule are relative to the
1976/// start time.
1977///
1978/// Set a start time by setting the kAudioUnitProperty_ScheduleStartTimeStamp
1979/// property with an AudioTimeStamp structure. If the timestamp contains a valid
1980/// sample time (timestamp.mFlags & kAudioTimeStampSampleTimeValid), then playback
1981/// begins when the timestamp passed to the AudioUnitRender function reaches the
1982/// specified sample time. If the specified sample time is -1, playback begins on
1983/// the next render cycle.
1984///
1985/// If the start timestamp does not contain a valid sample time, but does contain a
1986/// valid host time (timestamp.mFlags & kAudioTimeStampHostTimeValid), then the
1987/// specified host time is translated to the sample time at which playback will
1988/// begin. A host time of 0 means "start on the next render cycle."
1989///
1990/// The kAudioUnitProperty_ScheduleStartTimeStamp property may be queried to obtain
1991/// the time at which playback began. If the start time has not yet been reached,
1992/// the timestamp returned will be whatever the host application last set.

1994/// Current play time

1996/// The kAudioUnitProperty_CurrentPlayTime property may be queried to determine the

1998/// example, to monitor playback progress.
1999///                    
2000/// Unscheduling events
2001///
2002/// To clear an audio unit's play schedule, call the AudioUnitReset function. The
2003/// completion proc (if any) for each slice in the schedule will called. Playback
2004/// will not resume until a new start time has been set. This also happens when

2029///
2030/// This audio unit lets you schedule regions of audio files for future playback,
2031/// with sample-accurate timing.
2032///

2038/// converts audio file data into its own internal buffers. It performs disk I/O
