106/// The error constants unique to the HAL.
107///
108/// These are the error constants that are unique to the HAL. Note that the HAL's
109/// functions can and will return other codes that are not listed here. While these
110/// constants give a general idea of what might have gone wrong during the execution
111/// of an API call, if an API call returns anything other than os::Status::NO_ERR
112/// it is to be viewed as the same failure regardless of what constant is actually
113/// returned.

120
121    /// The function call failed while doing something that doesn't provide any
122    /// error messages.

131    /// property.

135    /// The requested operation couldn't be completed.
