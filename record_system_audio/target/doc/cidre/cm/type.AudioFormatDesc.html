pub fn as_be_sound_desc_cm_buf_in( &self, flavor: Option<&SoundDescFlavor>, allocator: Option<&Allocator>, ) -> Result<R<BlockBuf>>

Copies the contents of a CMAudioFormatDescription to a cm::BlockBuf in big-endian byte ordering.

Note that the dataRefIndex field of the SampleDescription is intentionally filled with garbage values (0xFFFF). The caller must overwrite these values with a valid dataRefIndex if writing the SampleDescription to a QuickTime/ISO file.
