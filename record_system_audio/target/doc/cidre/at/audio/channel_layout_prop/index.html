BITMAP_FOR_LAYOUT_TAG
Returns a bitmap for an AudioChannelLayoutTag, if there is one. The specifier is a AudioChannelLayoutTag containing the layout tag. The value is an u32 bitmap. The bits are as defined in CoreAudioTypes.h. To go in the other direction, i.e. get a layout tag for a bitmap, use kAudioFormatProperty_TagForChannelLayout where your layout tag is kAudioChannelLayoutTag_UseChannelBitmap and the bitmap is filled in.
